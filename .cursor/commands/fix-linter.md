Исправь все ошибки линтера в Go проекте:

**Шаги:**

1. **ОБЯЗАТЕЛЬНО:** Изучи текущую архитектуру проекта:
   - Прочитай файл `.cursor/rules/project-architecture.mdc`
   - Пойми структуру проекта и принципы Clean Architecture
   - Определи контекст компонентов для правильного исправления ошибок

2. Запусти golangci-lint и получи список ошибок:
   ```bash
   golangci-lint run
   ```

3. Запусти gofmt и goimports для форматирования:
   ```bash
   gofumpt -l -w .
   goimports -w .
   ```

4. Запусти go vet для дополнительных проверок:
   ```bash
   go vet ./...
   ```

5. Проанализируй каждую ошибку golangci-lint

6. Исправь ошибки согласно правилам проекта:
   - Все функции с явными типами возвращаемых значений
   - Совользуй gofumpt для форматирования
   - Используй goimports для импортов
   - Без комментариев в коде
   - Все строки на английском
   - Следуй принципам Clean Architecture
   - Используй context.Context для request-scoped данных
   - Избегай глобального состояния
   - Используй dependency injection

6. Убедись что исправления не нарушают функциональность

7. Запусти проверки повторно:
   ```bash
   golangci-lint run
   go vet ./...
   go test ./... -count=1 -race -timeout=60s
   ```

**Частые ошибки golangci-lint и их исправление:**

- **unused imports** - удали неиспользуемые импорты
- **unused variables** - удали неиспользуемые переменные или используй `_`
- **ineffective assignments** - исправь неэффективные присваивания
- **gofmt** - используй `gofumpt -l -w .`
- **goimports** - используй `goimports -w .`
- **gocyclo** - упрости сложные функции
- **goconst** - вынеси повторяющиеся строки в константы
- **misspell** - исправь опечатки
- **gosec** - исправь проблемы безопасности

**Правила исправления:**

- **НЕ добавляй комментарии** - код должен быть самодокументируемым
- **Всегда указывай типы возвращаемых значений** функций
- **Используй современный Go синтаксис** (Go 1.22+)
- **Следуй принципам Clean Architecture**
- **Используй dependency injection** вместо глобального состояния
- **Обрабатывай ошибки** правильно
- **Используй context.Context** для отмены операций

**Команды для автоматического исправления:**

```bash
# Форматирование кода
gofumpt -l -w .

# Организация импортов
goimports -w .

# Проверка линтера
golangci-lint run

# Проверка go vet
go vet ./...

# Запуск тестов
go test ./... -count=1 -race -timeout=60s
```
